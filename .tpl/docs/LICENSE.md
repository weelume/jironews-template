# 权利边界

参考设计为 https://jiro.build/templates/media-publishing/multi-categories-news-site-jironews 的公开预览。该页面显示 Premium；公开可见不代表获得其原始源码、设计和素材的商业再分发授权。当前实现为独立编写的演示，listed=false，redistributionAllowed=false；未确认权利前不得商业分发或上架。

照片按公开预览使用的 Unsplash URL 本地托管，完整来源见 ASSETS.json；原站404图片的替换和差异另行记录。每张照片的作者与具体许可尚待核实。

Poppins 保留 public/templates/jironews/fonts/Poppins-OFL.txt。MiSans 保留字体目录内现有许可记录，不从工具许可推断素材权利。协议工具许可在 tools/LICENSE，只覆盖工具。
